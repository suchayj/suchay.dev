# Owner recognition

Deploy the additive `20260915100000_owner_devices` migration before starting the new release. Generate the Prisma client and build normally. Do not reset or seed the production database.

After a successful login, CareerOS associates the existing first-party visitor cookie with the authenticated account and records a successful sign-in. Existing visits with that cookie are classified at query time; no visitor history is deleted. Visitors-only is the default filter, applied before pagination and metrics. All traffic and Your devices remain available.

Each browser profile is a distinct device entry. Rename the two Macs and iPhone after signing in on each. A cookie is not a hardware identifier or authentication credential. No IP matching or browser fingerprinting is used. Clearing cookies or using a private window creates a new identity. Historic logins cannot be reconstructed. Existing authenticated sessions should sign out and sign in once to register.

Owner recognition never grants access. All device reads and renames require authentication; renames are scoped to the current account. Successful-login records persist independently of session logout. The UI displays the latest 30 sign-ins.
